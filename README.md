# cafeteria-web

Sitio web de la cafetería **Café Aroma**: menú, horarios, ubicación y datos de contacto.

Proyecto académico de la materia **Desarrollo Web Integral** (UTC) para practicar control de versiones con Git y GitHub.

## Estructura

```
cafeteria-web/
├── index.html        # Estructura HTML del sitio
├── css/
│   └── estilos.css   # Estilos del sitio
├── img/              # Imágenes del sitio
└── README.md
```

## Flujo de trabajo

1. Cada integrante trabaja en su propia rama (`rama-menu`, `rama-estilos`).
2. Los cambios se registran con commits descriptivos.
3. Las ramas se suben con `git push` y se integran a `main` mediante Pull Request.

## Cómo verlo

Abre `index.html` en el navegador o visita https://jorgetl68.github.io/cafeteria-web/
